# 安装与排错

## 准备

从作者 GitHub Releases 下载完整 ZIP 与同名 `.sha256`，不要使用源码 ZIP 代替。完整解压，保留 `payload/`、`manifest.json` 和启动脚本的相对位置。需要 Python 3.10 或更新版本，不需要 pip 依赖。

准备能在 RPCS3 中运行的日版 BLJM60012 已解密文件夹。安装器会检查 PARAM.SFO、EBOOT 指纹和每个目标资源；ISO、加密转储、其他地区版或未登记汉化不能直接安装。先退出 RPCS3，再安装或恢复。

## 图形选目录与命令

Windows 双击 `安装或恢复.bat`，Mac 双击 `安装或恢复.command`，Linux 运行 `sh 安装或恢复.sh`。按菜单选择安装、只检查或恢复。支持系统目录选择器；没有 tkinter 时会改为输入路径。

本体可以选包含 `PS3_GAME` 的目录，也可以选 `PS3_GAME` 或其 `USRDIR`。更新目录要选 `dev_hdd0/game/BLJM60012`，不要选择它的 USRDIR。

如果 Mac 不允许双击启动脚本，打开终端输入 `sh `（末尾空格），将 `安装或恢复.command` 拖入终端，再回车。不要给 RPCS3 或安装器提权。

也可以在解压后的目录使用命令：

```sh
python3 install.py --game "/你的游戏/ARMORED CORE 4" --check-only
python3 install.py --game "/你的游戏/ARMORED CORE 4"
python3 install.py --game "/你的游戏/ARMORED CORE 4" --update "/RPCS3数据目录/dev_hdd0/game/BLJM60012"
```

Windows 将 `python3` 换成 `py -3`。所有包含空格的路径需用引号括住。

如果 RPCS3 已有 AC4 更新，请同时选择更新目录，确保其中的调校说明同步翻译。本发行适配的更新 USRDIR 只有 `regulation.bin`；遇到其他覆盖资源会停止。未安装更新的玩家只选本体即可。

## 备份与恢复

每次安装的原始资源与恢复日志存放在本体目录的 `AC4_CN_Backups/日期-编号/`。请保留整个目录，不能只保留 restore.json。备份只包含本次实际改动前的资源。

在启动菜单选「3」，选择含 `restore.json` 的备份目录，或运行：

```sh
python3 install.py --restore "/游戏/AC4_CN_Backups/日期-编号"
```

如果游戏已经移动，明确提供新路径：

```sh
python3 install.py --restore "/新游戏/AC4_CN_Backups/日期-编号" --game "/新游戏" --update "/新的更新目录/BLJM60012"
```

普通写入失败会尝试自动恢复；突然断电或结束进程后，安装锁会保留，用对应备份执行恢复。不要直接删除锁再重装。若资源后来被其他补丁修改，恢复会拒绝覆盖，避免破坏后续修改。

## 常见提示

- **找不到 Python**：安装 Python 3.10+；Windows 安装时启用 Python Launcher 或添加 PATH。关闭窗口再运行脚本。
- **所选游戏版本不符／原版资源不匹配**：确认 BLJM60012；本包要求特定原始资源。VERSION 01.05 是本发行 SFO 内的字段，不代表所有标为 1.05 的版本都兼容。请从自己的原始备份恢复后安装，不要强制跳过校验。
- **差分文件或清单损坏**：重新下载完整发行 ZIP，并完整解压。
- **检测到另一安装过程或未恢复的中断**：读取提示的备份路径，执行恢复功能。
- **空间不足**：需同时容纳原始备份与新资源，并保留 256 MiB 余量；本发行建议至少 600 MiB 空闲。
- **权限不足**：使用当前账号可写的游戏文件夹。不要把游戏放在只读磁盘或正在挂载的 ISO 内。
- **部分文字仍非中文**：部分型号、装饰文字和图片内文字保留；请用截图和页面名反馈遗漏。本发行没有宣称全游戏逐项验证。

## 下载校验

Mac 或 Linux 在下载目录运行（文件名按实际下载调整）：

```sh
shasum -a 256 AC4_CN_FullPatch_2026.09.25-delta.3_BLJM60012.zip
```

Windows PowerShell：

```powershell
Get-FileHash .\AC4_CN_FullPatch_2026.09.25-delta.3_BLJM60012.zip -Algorithm SHA256
```

将结果与同名 `.sha256` 内容比较。
