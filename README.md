## 安装

1. 完整解压 ZIP，退出 RPCS3。不要在压缩软件内直接运行。
2. Windows 双击“安装或恢复_Windows.bat”；Mac 双击“安装或恢复_macOS.command”。**Python 已内置，不用另装，也不需要联网下载依赖。** Windows 支持 x64；Mac 包含 Apple 和 Intel 环境。
3. 选择 1，输入自己的游戏目录（包含 PS3_GAME 的那层）。
4. 输入实际使用的 RPCS3 数据目录，里面应有 dev_hdd0 和 dev_hdd1。Windows 通常是 rpcs3.exe 所在目录，Mac 通常是 ~/Library/Application Support/rpcs3。多个模拟器副本要选正在使用的那个。
5. 工具会先核对并重建全部候选资源，再显示游戏和磁盘路径；确认后输入 y。未知资源、缺文件或更新目录含未适配覆盖文件时停止，不会先装一半再报错。
6. 安装完成后冷启动游戏，从游戏菜单加载普通存档。别用补丁安装前的模拟器即时状态验收新资源。

Mac 不能双击时，在终端运行 `zsh` 后接该 .command 的路径。不能单独搬走启动脚本或删除 runtime。安装不会替你关闭/启动模拟器，也不改 RPCS3 设置。

- delta.3 已有文本和修订，包括“小亚细亚”、群友校对、六章标题、菜单和教程、字幕换行/时序、连续“正在加载”、任务完成/失败及结算贴图修复。QB / OB / QT 保留。标题主菜单及 PRESS START BUTTON 仍保留英文。
- sourcehan-sans.1 思源黑体：中文动态字库和已汉化界面文字贴图统一为思源黑体 SC Regular，保留字码映射、字号和布局。
- 新的规制说明检查：本体松散表、bind/app 归档、已安装升级数据一起核对，处理 202 条零件说明、90 条稳定器说明及对应分类文字。已登记的日文文本补成中文，兼容规制只改文本槽，不改性能数值。
- 不再让已安装更新目录被无提示跳过。没有更新则报告没有，不替你安装新规制或覆盖 PARAM.SFO。有自定义规制时，结构、型号/厂商和原文必须与已适配记录相符，否则停止。
- AC4 旧安装缓存 `dev_hdd1/caches/BLJM60012_` 移到同磁盘备份，让下次启动重新生成；不清其他游戏或整个着色器缓存。
- 保留以前发布过的可选 START 跳过重试实验补丁，位于 optional，默认不启用。低特效/性能实验没有合入。

## 关于“读老档后介绍变回日文”

这是**实验性修复，不是已确认根因的彻底修复**。已发现旧安装流程可能只汉化本体、遗漏升级目录；规制数据也确实包含零件介绍。但“普通存档加载导致重读日文规制”的完整过程还没有在受影响玩家的机器上证实。

本版补上这个已发现的资源覆盖缺口，同时处理旧安装缓存。不读取、不转换、不修改个人存档，不是存档加载器。请反馈读同一个普通老档前后是否正常、退出重进后是否仍正常。

## 导入存档：先备份

**本版包含实验性修改。导入前务必备份自己已有的存档和准备导入的存档，不要覆盖唯一副本。**

退出 RPCS3 后，把实际 `dev_hdd0/home/用户编号/savedata` 下与 AC4 对应、以 BLJM60012 开头的完整文件夹复制到别处；用户编号通常是 00000001，以实际情况为准。剧情和机体设计可能分在不同目录，相关目录一起备份，不混合内部文件。

随后按 RPCS3 原有方式导入，冷启动后在游戏内读档，先检查机体、进度和零件介绍。若异常，退出并恢复自己的备份，不继续覆盖保存。异区或账号绑定存档不由本包转换。

安装器自动备份的是游戏资源，**不能代替存档备份**，也不会替你自动备份存档。

## 只检查和恢复

入口选 2 只检查，选 3 恢复。恢复时输入安装完成时显示的综合备份目录。

- 综合记录：游戏目录 `AC4_TextRepair_Backups/时间编号/repair.json`。
- 原资源：游戏目录 `AC4_CN_Backups/时间编号/restore.json`。
- 原安装缓存：`dev_hdd1/AC4_TextRepair_Backups/时间编号`。

重复安装会跳过已是目标的资源。安装中断会尝试回滚；如果断电，保留锁文件和备份，按锁里的路径恢复。综合记录未写完时可先选对应 restore.json 恢复资源，再保留缓存备份排查，不要强删锁掩盖中断。

恢复会核对原件和当前资源，拒绝覆盖后来被其他补丁改过的文件。若游戏已生成新缓存，先另存新缓存再恢复旧缓存。备份不会自动删除。建议至少预留 1 GB 空间；实际需要按文件和备份计算。

自定义 VFS 路径的用户应明确指定实际 dev_hdd0、dev_hdd1。例如 Windows 在本包目录运行：

    runtime\windows-x64\python.exe -B install.py --game "D:\Games\AC4" --hdd0 "D:\RPCS3\dev_hdd0" --hdd1 "D:\RPCS3\dev_hdd1" --check-only

普通布局可用 `--rpcs3 "D:\RPCS3"` 替代两项磁盘路径。去掉 `--check-only` 会预检后询问安装；`--restore "备份目录"` 用于恢复。不要选择未使用的旧数据目录后以为实际游戏已经修好。
