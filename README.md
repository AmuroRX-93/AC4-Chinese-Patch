# PS3《装甲核心 4》中文汉化补丁（BLJM-60012）

适用于 PS3 日版 **ARMORED CORE 4 / BLJM60012**，面向 RPCS3。游戏编号带横线与不带横线指同一版本。本发行基于已核对的日版资源；PARAM.SFO 的 **VERSION 为 01.05、没有 APP_VER**，并通过程序和目标资源指纹进一步确认版本，不能仅凭显示的版本号判断兼容。

本项目提供菜单、装备说明、任务文本、简报字幕及字库的中文差分补丁。需要你自己的匹配原版游戏，以及可选的已安装更新数据。不是游戏本体。

## 下载与安装

在 **[Releases](https://github.com/AmuroRX-93/AC4-Chinese-Patch/releases/latest)** 下载完整的 `AC4_CN_Delta_20260915_BLJM60012.zip` 和 `.sha256` 校验文件。**Code → Download ZIP 只有源码，不含差分数据。**

1. 准备已解密的文件夹版游戏，以及 Python 3.10 或以上。
2. 完整解压发行包，退出 RPCS3。
3. Windows 打开 `安装或恢复.bat`；Mac 打开 `安装或恢复.command`；Linux 运行 `sh 安装或恢复.sh`。
4. 选择「1 安装汉化」，然后选择包含 `PS3_GAME` 的本体目录。
5. 如果已安装 AC4 更新，选择同时处理更新，并选中 `dev_hdd0/game/BLJM60012`。没有安装更新则直接回车。
6. 等待显示安装完成，再启动游戏。

无需安装额外 Python 模块。安装器先核对全部选定资源、保存原版备份、重建并校验差分，再替换文件。已是本版的资源会跳过。

详细命令、恢复和报错处理见 **[安装与排错](docs/安装与排错.md)**。

- 可选更新只处理已登记的 `regulation.bin`。不会下载、安装或解锁更新内容。
- 专有缩写、型号、厂商名称、部分装饰英文和图片内文字保留；未制作所有图片标题的中文替换。
