## 下载与安装

在 [Releases](https://github.com/AmuroRX-93/AC4-Chinese-Patch/releases/latest) 下载 **AC4_CN_FullPatch_2026.09.25-delta.3_BLJM60012.zip** 与同名 `.sha256`。Code → Download ZIP 只有源码，不含差分数据。

1. 准备已解密的文件夹版游戏和 Python 3.10+，完整解压 ZIP，退出 RPCS3。
2. Windows 双击 `安装或恢复.bat`；macOS 双击 `安装或恢复.command`；Linux 运行 `sh 安装或恢复.sh`。
3. 选择安装，选中包含 `PS3_GAME` 的游戏目录。
4. 如已安装 AC4 更新，同时选中 `dev_hdd0/game/BLJM60012`；没有更新则跳过。
5. 安装完成后自行启动游戏。安装器不会启动模拟器。

支持原版首次安装、GitHub **2026.09.15-delta.1 / 2026.09.25-delta.2** 升级，以及清单登记的 9 月 24 日最终本地修订资源。只接受明确登记的资源哈希；其他版本或第三方修改会被拒绝。重复安装会跳过相同文件。

只保存实际改动文件的回退副本。详细命令和恢复步骤见 [安装与排错](docs/安装与排错.md)。玩家无需安装第三方 Python 模块。

本次正式发行包含未完成游戏内回归的修订，**正式发行状态不表示全部问题已验证解决**。静态资源、差分重建、安装/重复安装/恢复与故障保护的结果见 [发行验证](docs/发行验证.md)。Windows、Linux 和 PS3 实机尚未验证。
