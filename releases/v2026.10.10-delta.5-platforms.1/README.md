# AC4 中文累计差分包 · delta.5 · 三平台版 2026-10-10

适用于 PS3 日版 **BLJM60012 / 资源版本 01.05**。汉化资源与 2026-10-07 InstallerFix 完全一致；本版新增 Linux、Windows ARM64 和统一离线工具。这是独立完整累计包，不需要把小修复叠到旧包。

## 最快安装

1. 完整解压 ZIP 到空间充足的位置，不在压缩软件内运行。保留自己的原游戏和普通存档。
2. 正常退出 RPCS3，打开对应系统的“安装或恢复”入口。
3. 工具界面选择 **1 安装／更新／恢复**，在安装器界面再选择 **1 安装**。
4. 输入游戏目录：应直接包含 `PS3_GAME`。然后输入实际 RPCS3 数据目录：应包含 `dev_hdd0` 和 `dev_hdd1`。
5. 检查报告中的游戏、磁盘路径和变更数；确认后输入 `y`。工具先完成全部资源预检，再统一写入并备份。版本不符或存在未知覆盖文件时会停止。
6. 安装完成后冷启动游戏，从游戏菜单读普通存档；不要用安装前的模拟器即时状态验证。

**Python 已内置，Windows、macOS、Linux 都不需要另装 Python／pip 或联网下载库。** 本包不包含游戏本体、模拟器、固件、密钥和个人存档。

## 三平台入口与运行环境

| 平台 | 入口 | 内置环境 | 本次验证 |
|---|---|---|---|
| Windows x64 / ARM64 | 双击 `安装或恢复_Windows.bat` | Python 3.13.15，自动按架构选择 | 文件/架构/入口静态检查，未 Windows 执行 |
| macOS Apple Silicon | 双击 `安装或恢复_macOS.command` | Python 3.12.14 ARM64 | 包内环境、模块导入、校验及便携路径实际执行 |
| macOS Intel | 同一 `.command` 自动选择 | Python 3.12.14 x64 | 静态检查，未 Intel 执行 |
| Linux x64 / ARM64 | 终端 `sh 安装或恢复_Linux.sh` | Python 3.12.14，glibc 构建 | 官方摘要、架构和脚本检查，未 Linux 执行 |

入口以自己的目录定位，移动整个解压文件夹仍可用。不要单独搬脚本或删除 runtime。Windows 32位及 Linux musl/Alpine 不提供已适配运行环境。六套 Python 用于安装工具，不能由此推导所有硬件都能运行 PS3 模拟器。

Mac 解压后不能双击时：打开终端，输入 `sh `（末尾空格），把 `.command` 拖进去，回车。Linux 同理；或 `chmod +x 安装或恢复_Linux.sh` 后运行。若系统阻止，按系统正常授权处理，不关闭系统安全机制。

## 只检查、校验与恢复

- 校验下载包：首层工具选 **2**，会逐文件核对“全包校验清单.json”，发现缺失/损坏会报出文件并非零退出。
- 检查内置环境：首层工具选 **3**，显示包版本、实际解释器并导入累计修复模块。
- 只检查游戏：首层工具选 **1**，安装器选 **2 只检查**，填写游戏和实际数据目录，不写游戏。
- 恢复：首层工具选 **1**，安装器选 **3 恢复**，输入之前安装输出的备份目录。备份校验不符或资源已被之后的修改改变时拒绝盲目覆盖。
- 安装资源备份位于游戏的 `AC4_TextRepair_Backups`／`AC4_CN_Backups`；安装器打印的综合目录最准确。它不是个人存档备份。

## 正确的数据目录与更新覆盖

Windows 便携安装常在 `rpcs3.exe` 所在目录；Mac 常在用户资料库 `Application Support/rpcs3`；Linux 按安装方式和实际配置确认。多个模拟器副本必须选择正在使用的那个。

本包同时检查本体、已安装 AC4 更新和旧安装缓存。已知更新中的规制说明只改文本，不改性能数值；没有更新时不会新装更新。旧 AC4 缓存 `dev_hdd1/caches/BLJM60012_` 会移到备份，下一次冷启动重建，不清其他游戏缓存。

若 VFS 自定义映射，安装器会停止，不能靠默认路径猜。使用包内对应架构 Python 执行：

```
包内Python -E -s -B install.py --game "游戏目录" --hdd0 "实际dev_hdd0" --hdd1 "实际dev_hdd1" --check-only
```

先只检查；核对后去掉 `--check-only` 按提示确认安装。Windows Python 在 `runtime/windows-x64/python.exe` 或 `windows-arm64/python.exe`；Mac/Linux 在 `runtime/平台名/python/bin/python3`。不要改成系统 Python。路径含空格时完整加双引号。

## 基线、旧版升级与版本识别

支持正式清单登记的原版及旧汉化、思源黑体版本，累计安装无需按顺序跑多个旧包。资源 VERSION 01.05 与汉化发行号不是同一个概念；文件夹名或版本字符串不能代替哈希匹配。混合资源、未知规制、缺文件不会强装，保留报错和原件便于核查。

如果已经使用最新 delta.5 资源，通常无需重复改本体；本次是安装器与跨平台交付升级，不是新增剧情翻译。

## 存档保护

导入任何他人存档前，先备份自己的相关完整存档文件夹及源存档。工具不读取、不转换、不修改 savedata；资源备份不能代替存档备份。旧存档说明变回日文的问题仍是实验性修复，不能保证全部解决。

## 安卓与 PS3 实机

本包是桌面差分安装器，桌面 Python 不能直接在 Android 或 PS3 上运行。安卓或实机玩家可先在电脑合成目标资源，再按目标模拟器/加载器支持的目录导入；不能把 ZIP 当 APK／PKG，也不能只改扩展名变 ISO。数据读取优先级、CFW/HEN 签名和具体模拟器支持均须另核对。本次未提供已验证的安卓程序或实机 PKG，也未实测这些平台。

## 来源、许可与排障

Python 来源、下载摘要和修改项在“Python来源.json”；第三方许可证随包。Linux 链接展开为普通文件，移除在某些大小写不敏感文件系统中冲突的 terminfo 终端数据库；本工具不使用 curses，未由此宣称所有 Python 功能均经测试。

报错先看第一条错误，结尾“按任意键继续”不是根因。缺模块时先确认完整解压和目录层级，不用 pip 安装同名包。校验失败或版本未知时保留完整错误及文件名，不强行删除更新/存档。
