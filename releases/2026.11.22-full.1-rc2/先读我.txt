# AC4 完整累计汉化 11.22 RC2（三平台工具版）

PS3 日版 BLJM60012 / 资源 VERSION 01.05，完整累计测试版。
**一个包即可从已登记的原版或旧汉化安装，无需先装 delta.5 或旧增量补丁。**
不直接修改 ISO；请选择包含 PS3_GAME 的已解密游戏目录。

## 安装、检查、恢复

1. 完整解压，退出 RPCS3。不要在压缩软件里运行，不要只拷贝一个脚本。
2. Windows 双击 `安装或恢复_Windows.bat`；macOS 双击 `安装或恢复_macOS.command`；Linux 执行 `sh 安装或恢复_Linux.sh`。
3. 选择“安装／更新／恢复”，再选择安装。输入游戏目录和实际使用的 RPCS3 数据目录（内有 dev_hdd0、dev_hdd1）。按预检提示确认。
4. 完成后正常冷启动游戏，从菜单读取普通存档。不要用安装前的模拟器即时状态判断补丁效果。
5. 撤销时用同一入口选择恢复，填入安装时显示的 `AC4_TextRepair_Backups/时间编号` 路径。资源备份位于 `AC4_CN_Backups`，请保留直到不再需要还原。

已安装本版可重复运行，正确资源不会重复追加。未知文件版本、缺少分卷或冲突会在写入前停止。预检与提交期间不要修改游戏文件。失败会尝试统一回滚；后续被其他补丁改过的文件不会盲目覆盖。只迁移本游戏旧安装缓存到备份，不清除其他游戏或全局着色器缓存；不读写用户存档、手柄或模拟器图形配置。

主菜单也提供下载包完整性校验和环境检查。需要至少 2GB 临时/备份空间，具体还受原目录和更新内容影响。

## 已安装更新与自定义目录

自动按内容、已登记哈希及大小写不敏感相对路径识别更新目录资源。支持已知的 EBOOT、规制、嵌套菜单/归档、附属说明和空目录；更新与本体放在同一次事务内处理。不删除更新目录，不改 PARAM.SFO。未知有效程序/归档仍会停止。

多个 RPCS3 副本需选择实际使用的数据目录；自定义 VFS 映射请使用命令行：

```
runtime/macos-arm64/python/bin/python3 -E -s -B install.py --game "游戏目录" --hdd0 "实际 dev_hdd0" --hdd1 "实际 dev_hdd1" --check-only
```

移除 `--check-only` 会预检并询问安装。`--restore "备份目录"` 用于还原。Windows 使用对应 runtime 下的 python.exe，其他系统/CPU 使用相应目录。

## 平台和验收范围

安装/检查/恢复工具内置 Windows x64/ARM64、macOS Apple Silicon/Intel、Linux x64/ARM64（glibc）六套 Python，不要求另装依赖或联网。
本轮 macOS ARM64 用真实资源的隔离目录验证升级、重复安装、完整还原、更新目录同步、未知文件拒绝和差分损坏拒绝。原版首次安装沿用正式 delta.5 的既有差分与原版指纹覆盖；本轮没有重新找一张完整原版光盘跑全流程。
315 槽参数栏修复有 10 月 28 日的 macOS 游戏运行记录；UI/标题和新完整组合没有本轮游戏内验收。**本次没有启动模拟器，仍按测试版发布。** Windows/Linux/Intel 本轮仅静态检查；完整剧情、战斗和跨平台游戏运行未测。

新增加载保护程序是 RPCS3 debug SELF。安卓模拟器、PS3 CFW/HEN 兼容性未验证；本包不是 APK/PKG，不能宣称手机/实机已支持。若在电脑处理后转移到其他平台，须自行验证其 debug SELF 支持；普通未改 PS3 不能直接使用。没有商业签名主机程序或固件。不要把电脑安装工具的系统覆盖等同于三个游戏平台已验收。
