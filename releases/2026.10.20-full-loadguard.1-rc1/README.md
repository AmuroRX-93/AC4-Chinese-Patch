# AC4 完整累计汉化 + Normal / 零件说明加载保护

版本：2026.10.20-full-loadguard.1-rc1（完整合并测试版）
游戏：PS3 日版《装甲核心4》BLJM60012，资源基线 VERSION 01.05。

**这一个包即可从已登记的原版日版游戏目录安装完整汉化及本次修复，不需要先装 delta.5，也不需要再运行独立热修包。** 包内不含游戏本体。

## 一次安装

1. 完整解压，正常退出 RPCS3。
2. Windows 双击 `安装或恢复_Windows.bat`；Mac 双击 `安装或恢复_macOS.command`；Linux 运行 `sh 安装或恢复_Linux.sh`。包内包含 Windows、macOS、Linux 的 x64/ARM64 Python，无须联网安装依赖。
3. 选择“安装／更新／恢复”，再选择“安装汉化及修复”。
4. 输入包含 `PS3_GAME` 的游戏目录，以及正在使用的 RPCS3 数据目录（包含 `dev_hdd0` 和 `dev_hdd1`）。程序会列出预检结果，确认后一次安装全部内容。
5. 安装完成后冷启动游戏。不要用安装前的模拟器即时状态检验；需从游戏菜单读取普通存档。

只需检查时选择“只检查”；下载完整性可从最外层入口选择“校验此下载包”。如果包内文件缺失，请重新完整解压，不要单独移动安装脚本。

## 包含内容

- 正式 delta.5 的全部累计汉化、思源黑体、已有菜单/教程/任务字幕、最终关六处字幕引用修复、片尾中文字幕及规制文本修复。
- AC TEST 目标类型改为准确的 **Normal**。只修改对应文字对象，保留该资源的贴图成员。
- 加载零件表时保护 202 条中文零件说明；校验表头与全部部件编号后覆盖说明，保留性能数值。这是零件说明保护，不是重载所有贴图和字幕。
- 安装器先准备并验证完整资源，再统一提交。汉化和新增程序修复共用一份安装记录及回退入口；不是串行运行两个独立安装器。

支持已登记的原版及旧汉化输入，也支持本合并版重复安装；未知文件版本会在写入前停止。原正式累计汉化差分载荷保持逐字节一致。本包不是 10 月全部未发布改动的合集；内容基于 delta.5 正式包和本次 rc1 修复。

## 备份与回退

本工具不读写用户存档。重要存档请自行另存，资源回退备份不能代替存档备份。

安装完成会显示 `AC4_TextRepair_Backups/时间编号` 的完整路径；回退时从同一入口选择“恢复”，填写这个目录，即可一次撤销全部本次修改。实际资源备份位于 `AC4_CN_Backups/时间编号`。AC4 旧安装缓存会移到同磁盘备份，下次游戏启动重建；不清空其他游戏或全局着色器缓存。

回退会核对当前文件和备份；如果之后被其他补丁改过，会拒绝覆盖。安装失败会尝试统一回滚。请保留本次备份直到验收完成；至少预留 2 GB 临时空间，安装器还会核算实际需求。

## 已装更新和自定义目录

安装器处理已适配的 AC4 更新规制；未知更新覆盖文件会拒绝写入，不替你安装新规制或覆盖 PARAM.SFO。多个模拟器副本必须选择实际使用的目录。

自定义 VFS 将 dev_hdd0 / dev_hdd1 分开映射时，在包目录以对应内置 Python 调用：

```sh
runtime/macos-arm64/python/bin/python3 -E -s -B install.py --game "/path/AC4" --hdd0 "/path/dev_hdd0" --hdd1 "/path/dev_hdd1" --check-only
```

移除 `--check-only` 会预检后询问安装。`--restore "/path/AC4_TextRepair_Backups/时间编号"` 用于回退。按当前系统和架构选用 runtime 子目录；Windows 解释器在 `runtime\windows-x64\python.exe` 或 ARM64 对应位置。

## 验证范围与测试版说明

合并器在隔离目录实测一次写入 276 个资源、校验、重复安装无变化及完整回退；新增输出与旧累计包相比仅三个预期文件变化（EBOOT、AC TEST 松散菜单和归档）。旧完整汉化的差分载荷未改。具体结果见 `合并安装验证.json`。

此次输入测试集包含 258 个原版哈希匹配文件和 21 个已登记中文资源，并非重新验收一张全新完整日版光盘。原版支持沿用正式累计包已登记的差分及其既有验证。Windows/Linux/Intel Mac 未实际执行安装，本机验证使用包内 macOS ARM64 Python。

此前独立、无窗口、静音 RPCS3 测试中，带诊断标记的同版程序在真实 PPU 解析路径两次完成 202 条日文说明恢复中文；发行程序不含诊断输出。**从游戏菜单读取旧日版存档的完整交互流程、Normal 本次画面验收仍待完成。** 本包保留测试版标记，不能把安装校验通过当作全部游戏场景验收通过。

## 安卓和 PS3 实机

本包是游戏目录差分安装器，不是 APK 或 PKG。可在电脑处理游戏目录，但新增程序为 debug SELF，安卓模拟器和 PS3 CFW/HEN 兼容性尚未实测；未越狱零售主机不能直接运行。当前建议用于独立 RPCS3 测试目录，不宣称三端均已验收。
