# AC4 中文增量测试包：Normal 与零件说明加载保护

版本：2026.10.20-loadguard.1-rc1。适用于日版 PS3 BLJM60012，已安装 delta.5 思源字库的游戏目录。**这是测试版，不取代 2026-10-10 正式版。**

本包修正 AC TEST 的目标类型名称为用户指定的 **Normal**，并在 AcParts 零件表每次进入解析器时覆盖 202 条中文说明。保护针对零件说明；没有声称重载整套字库、贴图、任务字幕或所有存档数据。原有数值、部件编号及其他菜单项目保持不变。兼容结构以表头和全部部件编号校验，未知结构跳过覆盖。

## 验证范围

- 六组覆盖循环测试：日文、已有中文、数值变化、未知表头、最后一个部件编号不匹配、空指针。测试覆盖描述与数值保留；此项用 PPC32 执行共享覆盖循环，不冒充完整 PPC64 仿真。
- RPCS3 0.0.42-20021 / macOS ARM64，无窗口静音独立测试：人为放回日文表后，带诊断标记的候选在真实 PPU 解析路径上两次报告完成 202 条中文恢复，没有无效跳转或内存访问错误。发行候选不包含这些诊断输出。
- SELF 回读后内嵌 ELF 与候选逐字节一致。安装、重复安装、回退结果见随包的安装器验证记录。
- **尚未验收：从游戏菜单选择旧日版存档后的完整交互流程、Normal 的本次画面验收、安卓模拟器、PS3 实机。** Windows / Linux / Intel Mac 入口与运行时只完成文件完整性和静态检查，未在这些系统运行游戏。

## 电脑安装

1. 先安装正式 delta.5 累计汉化，退出 RPCS3。新下载的本包不能独立把日版变成完整汉化。
2. 完整解压本包，在 Windows 双击 `安装或恢复_Windows.bat`，macOS 双击 `安装或恢复_macOS.command`，Linux 运行 `sh 安装或恢复_Linux.sh`。内置 x64 / ARM64 Python，无需安装 Python 或 pip。
3. 选择安装，填写包含 `PS3_GAME` 的游戏目录。可先选择“仅预检”。
4. 如果使用 RPCS3，填写其实际数据目录，以同步其中已有的 AC TEST 菜单缓存和更新副本。常见目录：Windows 为 RPCS3 可执行文件旁；macOS 为 `~/Library/Application Support/rpcs3`；Linux 通常为 `~/.config/rpcs3`。便携模式或自定义 VFS 的用户必须提供实际数据位置；本工具不自动修改 VFS，也不盲猜自定义盘符。若 `/dev_hdd0` 与 `/dev_hdd1` 分开自定义映射，应先在各实际位置分别应用对应菜单资源或等待后续专用支持。
5. 安装器核对 EBOOT 和 10 页兼容字库，再只改必要文件。未知 EBOOT、字库或菜单结构会拒绝写入。已有贴图成员不被旧版贴图替换。

命令行（以 macOS 为例，另外两个入口支持相同参数）：

```sh
./安装或恢复_macOS.command --doctor
./安装或恢复_macOS.command --game "/path/AC4_BLJM60012"
./安装或恢复_macOS.command --game "/path/AC4_BLJM60012" --rpcs3 "/path/rpcs3-data" --apply
```

macOS 如果阻止启动，请先检查下载来源与文件完整性，并按系统的正常“打开”流程处理；本工具不关闭系统安全保护。Linux 运行时要求 glibc。

## 回退

只备份修改的小文件，不复制整个游戏，也不改存档。备份位于游戏根目录 `.ac4-cn-backups/`，安装完成会显示 `restore.json` 的确切路径。关闭 RPCS3，选择“回退”并填写该路径，或运行：

```sh
./安装或恢复_macOS.command --restore "/path/AC4_BLJM60012/.ac4-cn-backups/本次目录/restore.json"
```

备份和当前文件都会先校验；如果当前文件又被其他补丁改过，工具拒绝覆盖。请保留本次小备份直到自行验收完成。没有删除存档、清空全局缓存或重置设置的操作。

## 安卓与 PS3 实机边界

这是 PS3 游戏目录的增量工具包，不是安卓 APK，也不是 PS3 更新 PKG。电脑完成差分后可得到同一份修改后的游戏目录，但**本次程序为 debug SELF，手机模拟器和 PS3 CFW/HEN 的实际兼容性尚未验证**；请勿把它当作已验证的三端正式发行。未越狱零售主机不能直接运行此修改。当前建议仅在独立 RPCS3 测试目录使用，保留可玩正式版。

## 反馈时提供

平台、游戏编号、使用的正式汉化包版本、规制版本、从标题界面读档还是加载模拟器即时存档，以及出问题的部件型号即可。不要上传自己的完整存档或账号信息到公开 issue。即时存档会恢复旧进程内存，不等同普通游戏存档；测试本包请完整退出后重新启动游戏再读档。
